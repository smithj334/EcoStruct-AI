**Student Name:** Jonathan Smith  
**Project Track:** Conceptual Design Track  
**Date:** Spring 2026  

## Project Description
EcoStruct AI is a conceptual framework for an automated site feasibility and structural parameter prediction agent. Designed for the Architecture, Engineering, and Construction (AEC) industry, this AI solution evaluates potential construction sites for large-scale 3D concrete printing. By analyzing topographical data, historical local weather patterns, and regional building codes, the AI generates predictive concrete volume requirements, optimal structural specifications, and financial cost models to determine if a site is viable for automated additive manufacturing.
